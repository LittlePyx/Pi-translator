Pi Translator

在 Overleaf 和普通网页中翻译选中文本，并按需保护 LaTeX 结构。

有选区：快捷翻译 无选区：打开设置 Alt + Shift + T

数据说明

只有你主动触发翻译的选中文本和已配置的相关术语约束会发送到 DeepSeek API。本扩展默认不保存翻译历史，也不会把 API Key 暴露给网页。

DeepSeek API

默认仅保存在当前浏览器会话。持久保存更方便，但不代表操作系统级加密。

使用当前输入或已保存的 API Key 从 DeepSeek 获取模型列表。

翻译偏好

“自动判断”会在 Overleaf 中启用 LaTeX 保护，在普通网页检测到公式或命令时自动保护。

学术术语表

页面范围

只在语言特征足够明确时隐藏；短文本、混合文本仍会显示。右键菜单和快捷键始终可用。

使用方式

普通网页的推荐模式不会持续读取页面：选中文本后使用右键菜单或按 Alt + Shift + T，扩展只临时获得当前页面权限。
