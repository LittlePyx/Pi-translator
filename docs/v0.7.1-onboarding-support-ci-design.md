# Pi Translator v0.7.1：首次向导、支持工具与 CI 设计

## 目标

v0.7.1 降低首次配置和故障排查成本，同时保持网页浮层与日常设置页清爽。新增能力集中在首次启动的模态向导和设置页底部的紧凑支持区，不向翻译卡片或侧栏继续堆叠常驻按钮。

## 三步首次向导

1. 用户选择预设接口或自定义 OpenAI 兼容接口。
2. 用户填写 API Base URL 与 API Key，扩展仅申请该 API 源站的可选权限，并尝试读取可用模型。
3. 用户确认模型并测试连接，成功后保存设置。

Key 默认进入浏览器会话存储；只有用户明确勾选时才持久保存在本机。旧版本升级时不自动弹出向导，避免打断已有用户；设置页提供“重新运行首次设置”入口。

## 安全配置迁移

导出 JSON 只包含接口名称、Base URL、模型和用户偏好，并固定写入 `containsApiKeys: false`。内部配置 ID 不导出。导入时执行格式校验、数量限制、URL 规范化、枚举白名单和术语清洗，并重新生成配置 ID。

导入成功前先完成解析和校验；导入落盘时清除所有旧 API Key，并强制恢复为会话 Key 模式，防止旧 Key 被无意用于新导入的 API 地址。

## 本地诊断报告

后台只在失败时记录结构化摘要：时间、操作类型、错误代码、是否可重试和可选 HTTP 状态码。最多保留 20 条，并使用会话存储。

报告包含扩展版本、浏览器环境、当前 API 的非密钥配置状态、行为开关和错误摘要。报告明确排除 API Key、错误正文、选区、译文、页面 URL、术语条目和网站名称。只有用户点击“复制诊断报告”后才进入剪贴板，不会自动上传。

## 自动验证

GitHub Actions 在 Windows 与 Microsoft Edge 环境中依次执行：

1. 安装锁定依赖；
2. 扫描常见 API Key 和私钥头；
3. TypeScript 类型检查；
4. Vitest 单元测试；
5. Edge MV3 生产构建；
6. 真实 Edge 端到端测试；
7. 生成并上传可安装 ZIP 工件。

宣传截图脚本与回归测试分离，避免视觉素材生成故障被误判为产品功能回归。
