Test steps:
1. Install the extension; its settings page opens automatically.
2. Configure the text provider, paste the text Key, connect, and save.
3. Open any public HTTPS article, select an English sentence, and choose “使用 Pi Translator 翻译选中文本” from the context menu. Verify streamed translation, copy, correction, and the pinned sidebar.
4. Optional recovery test: temporarily enter an unavailable model, trigger a translation, use the directed settings action, restore the model, and return to the original tab.
5. Optional PDF test: configure the vision provider, open “PDF 阅读器”, choose a local PDF, and translate selectable text or a user-confirmed image region.
6. Optional native-PDF test: open a PDF directly in Edge, select text, and use the same context-menu command; the result streams in Edge’s side panel.

No Microsoft, Overleaf, or Pi Translator account is needed. API requests go directly to the selected provider. Keys are entered only in extension settings, are not bundled in the ZIP, and are not exposed to webpages. The extension executes no remote code.
