# Pi Translator v0.8.1

这是 v0.8 系列的功能与稳定性更新。

## 主要更新

- 新增“本文”记忆：最近译句、固定译法、待确认术语，以及候选译法修改后采用。
- 译文中的 LaTeX 可在本地安全渲染，并保留“源码/公式”切换；复制仍得到原始 LaTeX。
- 改进网页渲染公式捕获和 PDF 多模态公式识别，低清 PDF 可通过框选翻译并输出公式源码。
- 改进 Pi PDF 的划词吸附、连续框选、任务队列、阅读状态恢复、本文标记与侧栏自适应布局。
- 翻译中固定到侧栏后继续保持流式输出；长文支持分段恢复和更及时的完成状态。
- 减少公式结构校验造成的重复重试，并兼容多行公式环境中的编号显示。

## 安装

1. 下载 `tex-selection-translator-0.8.1-edge.zip` 并解压。
2. 在 Edge 打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压后的文件夹。
5. 打开 Pi Translator 设置页，填写自己的兼容 API 地址、API Key 和模型。
