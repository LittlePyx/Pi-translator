# Pi Translator v0.5 设计说明

## 目标

v0.5 在不改变“用户主动选中文本后翻译”这一单一用途的前提下，增加三项能力：

1. 用户配置自己的 OpenAI 兼容 API；
2. 在当前标签页查看最近 5 条翻译；
3. 在完整译文和逐句对照之间切换。

## API 兼容层

设置由 `API Base URL + API Key + model` 组成。扩展调用标准的 `POST /chat/completions` 和 `GET /models`，使用 Bearer Token 鉴权。远程接口必须使用 HTTPS，本机 `localhost`、`127.0.0.1` 和 `[::1]` 可以使用 HTTP。

扩展清单只声明 HTTP/HTTPS 为可选网站权限。用户保存、读取模型或测试连接时，扩展只请求所填写 API 的具体 origin。翻译前后台会再次核对权限；缺少权限时引导用户回到设置页授权。

这套接口覆盖采用 OpenAI Chat Completions 协议的服务，但不声称兼容具有不同鉴权或请求结构的私有协议。

## 最近翻译

- 使用 `browser.storage.session`，不写入持久存储；
- 按标签页 ID 隔离，每个标签页最多 5 条；
- 相同原文再次翻译时以新结果替换旧记录；
- 关闭标签页、关闭浏览器、关闭该功能或点击“清空记录”时删除；
- 卡片提供上一条、下一条、计数器和 `Alt+↑` / `Alt+↓` 快捷键。

## 逐句对照

原文在扩展本地通过 `Intl.Segmenter` 切分，降级时使用标点规则，并生成稳定 ID（`S1`、`S2`……）。所有句段在一次请求中发送，使模型保留上下文；响应只接受与本地 ID 对应的译文。

卡片中的原句始终来自用户本地选区，不采用模型回传的原文。LaTeX 模式为完整文本和每个句段使用独立占位符命名空间，分别校验并恢复。逐句结果缺失或校验失败时，完整译文仍然可用。

## 界面

翻译卡片包含：历史导航、完整译文/逐句对照切换、复制、重新翻译、清空记录和关闭操作。卡片保持可拖动，并根据网页实际主题自动切换深浅配色。

设置页把接口地址、域名授权状态、密钥和模型放在同一视觉区域；会话记录与默认逐句视图放在独立偏好卡片中。所有敏感数据说明与权限请求均在对应操作附近展示。

## 隐私边界

P&I Lab 不提供中转服务器。选中文本、可选翻译约束和 API Key 直接用于用户配置的第三方接口。最近翻译只存在于扩展会话存储，API Key 默认也只保存在会话中。完整披露以根目录 `PRIVACY.md` 为准。
