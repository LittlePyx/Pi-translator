## v0.14.0 初始候选记录（2026-08-27）

本版本为普通网页增加正文双语阅读，并为普通网页与 Overleaf 增加一次性区域框选翻译。正文模式保留原网页，只在主要段落下方插入译文，跳过导航、表单、表格、代码块和独立公式；先处理当前视口与下一屏，滚动后继续，可暂停、停止后继续或清除。待发送段落会跟随当前阅读位置重排，视口内容优先于已经离开的旧队列，同时保留进行中请求和用户主动重试的优先级。超过 350ms 的当前段请求会显示一行浅色等待提示，完成或失败后原位替换；快速请求、排队段落、只看原文与主动翻译抢占均不会留下多余占位。网页控制条与 Edge 侧栏可无请求地切换“双语 / 译文 / 原文”，动态加载的新译文继承当前模式。“只看译文”只隐藏已有成功译文的原文；代码、独立公式、未译或失败段落，以及单独隐藏译文的段落仍保留原文，避免空白或信息丢失。无限滚动和前端动态加载的新段落会在接近视口后自动加入，相同文本重渲染会复用已有译文；暂停或停止期间不发送新增请求，SPA 换文章时清除旧译文并提示重新开始。同一标签页刷新并再次打开 Pi Translator 后，会从当前浏览器会话恢复与页面、正文、目标语言和翻译配置匹配的译文、范围及阅读模式，只请求变化和新增段落；页面控制条与 Edge 侧栏显示恢复段数。会话不保存原始页面 URL 或段落原文，主动清除、设置变化、关闭标签页或关闭 Edge 时删除。段落请求会把文章标题、紧邻上一段及上一段已完成译文作为最多 800 字符的临时参考，模型仍只输出当前段，参考内容不产生额外请求也不写入历史。译文悬停或键盘聚焦后可复制、隐藏/显示或仅重译当前段，单段重译失败仍保留原译文与整页进度。单段长度、空结果、异常格式或 LaTeX 保护问题会就地显示“重试本段”而不阻塞其余正文，连续失败及限流、网络、鉴权等全局问题会暂停后续请求；临时段落请求不写入划词历史。正文运行中发起划词、右键或框选翻译时，当前选区优先，正文自动让路并在结束后续跑，被替换的段落不会误报失败。网页区域框选只有在用户再次确认后才截取当前可见页中的选定区域，并始终交给多模态模型；密码、验证码和支付字段始终阻止发送。本轮同时升级 Node.js 24 CI 与发布流程。发布门禁如下：

正文目标语言现会在快捷面板、Edge 浏览器侧栏和网页控制条中同步显示。无译文时直接切换；存在译文时，界面会明确显示将清除的已译段数并要求再次确认，取消不会清除正文译文或调用接口。长文章在用户打开 Pi Translator 后还会显示轻量“译全文 · N 段”入口；判断相对当前目标语言，只统计非目标语言的可翻译正文，短页面、代码或表单内容和目标语言页面不显示。入口可避开网页固定浮窗与 Pi 页面侧栏，Edge 浏览器侧栏打开时去重，窄屏把次要操作收进更多菜单。正文范围预览可逐段排除或恢复，取消零请求，应用后复用未变化结果并只处理实际增删的段落。正文完成后网页控制条自动折叠为轻量胶囊，低频操作集中到“更多”，手动展开/折叠状态可随会话恢复。KaTeX、MathJax 与 MathML 内联公式会合并为唯一 TeX 源并严格保护，译文再渲染为 MathML；旧版 MathJax 的可见公式与隐藏源码不会重复进入请求，独立公式仍保留原文。

对于图片、SVG、Canvas 或缺少 TeX 源码的公式，正文模式会剔除不可读的视觉节点后仅翻译周围文字，保留原网页公式，并阻止“只看译文”隐藏该段原文。译文旁的“框选识别”会预选当前段落；打开、调整和取消选框均为零请求，只有确认后才进入既有多模态截图流程。
