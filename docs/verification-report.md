## Manifest 检查

最终 Manifest 满足以下约束：

- 必需网站权限只有 DeepSeek API 和 Overleaf。
- 普通 HTTP/HTTPS 网站位于 `optional_host_permissions`。
- 静态 `content_scripts` 只包含 Overleaf 项目页。
- 普通网页脚本作为独立构建产物，由用户操作临时注入或在授权后动态注册。
