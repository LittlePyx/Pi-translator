## 未发布手工修正增量（2026-08-08）

- 普通网页、Overleaf、Pi PDF 共用的翻译卡片，以及 Edge 原生 PDF 的独立侧边栏，均在翻译完成后提供低占用的“修正”入口；流式输出期间不显示可保存的修正编辑器。
- 编辑器按译文结构拆分自然语言与 LaTeX：自然语言片段可编辑，公式、命令及其边界以只读片段锁定；后台再次比对受保护片段，拒绝增删、改写或换序后的提交。
- 手工保存不调用翻译提供商。译文保存范围只有“仅本次”和“记住本文”；固定术语默认收起且可选，并独立选择保存到本文或全局。只有用户明确填写术语原文和固定译法时才会写入术语，不会从整句修改中自动提取。
- 逐句对照中的“修正”在本地只替换目标译句，不调用翻译 API；其余译句、对齐关系和受保护公式保持不变，最近一次单句修正可以撤销。
- 翻译结果、保存和撤销均校验当前请求标识与译文内容，并在同一标签页内串行提交；后台记录当前结果头，旧编辑器、旧翻译结果或过期撤销不能覆盖新译文。Edge 原生 PDF 还同时校验 PDF 会话和修正回执。译文与本文术语同时选择本文范围时在一次本地原子写入中提交；撤销术语时仅在当前映射仍等于本次修正写入值时回滚，用户后续修改不会被覆盖。
- 结果头缺失会按过期修正拒绝；最终结果头通过比较并交换提交，提交前发生的本文记忆、本文术语或全局术语写入在失败时按相反顺序执行条件补偿。Edge 原生 PDF 的会话替换、重试、修正、撤销、文档导航与标签页清理均按标签页排序，避免失败响应伴随部分落盘或旧会话复活。
- 同 URL 刷新会旋转标签页文档生命周期并终止旧任务；文字与图像翻译先同步提交结果头及匹配的 Edge 原生 PDF 可恢复侧栏会话，成功后才执行历史、缓存和本文记忆维护。恢复确认也受同一生命周期和标签页提交通道保护。本文术语回执保留被确认操作移除的候选，撤销与失败补偿均不会静默丢失候选。
- 四条文字/图像实时与缓存完成路径均经过提交屏障：流式预览不受影响，结果头和匹配的 PDF 会话提交成功后立即显示完成结果，历史、缓存和本文记忆仍在后台收尾；提交或页面生命周期失败时不会先显示一个无权威状态的完成结果。
- 设置写入通过扩展同源锁跨后台、快捷面板和设置页串行化；设置页保存使用三方合并，只覆盖用户实际改动的字段，保留并发语言、API 配置和术语更新。超过 API 配置或术语容量时明确阻止保存，不做静默裁剪。
- API Key 映射的迁移、保存、清除和存储位置切换使用同一个跨页面写锁；接口地址变化、配置删除、首次设置和配置导入均先隔离可能关联旧接口的 Key，再提交新设置并写入用户提供的新 Key。中途失败最多留下“缺少 Key”的安全状态；同一接口只切换模型不会要求用户重复填写 Key。
- 保存待填写 Key 前会对打开设置页时的配置 ID 与接口地址做条件校验；其他页面已经删除配置或更换接口时整次保存失败关闭，不产生孤立 Key。本文记忆的容量补偿不会淘汰回执之后新增的无关翻译，空间不足时安全跳过旧记录恢复。
- 修正后的结果继续沿用最近翻译、本文记忆、原文标记和 Edge 原生 PDF 会话的现有同步路径；撤销后这些视图同步恢复，不保留已撤销版本作为当前结果。
- `Escape` 在译文修正、逐句修正、OCR 原文编辑和更多菜单中优先处理当前子界面，并恢复到对应触发按钮；Pi PDF 阅读器的框选快捷键不会同时改变状态。复制结果在原按钮或既有状态区内反馈，不增加常驻提示控件。
