# Pi Translator v0.3：交互与视觉升级

> 状态：已实现
>
> 日期：2026-07-23

## 1. 目标语言选区抑制

普通网页启用浮动按钮时，如果选区被本地规则高置信度判断为目标语言，则不显示浮动按钮。

原则：

- 只影响自动浮动按钮，不影响右键菜单和快捷键。
- 短文本、数字为主和混合语言文本继续显示按钮。
- 中文使用汉字占比判断。
- 日文要求出现假名，避免把纯汉字中文误判为日文。
- 英语、德语、法语结合常见词和特征字符评分。
- 不支持的目标语言不做猜测。
- 设置页提供独立开关，默认开启。

该判断完全在本地完成，不会为了决定是否显示按钮而调用翻译 API。

## 2. 快捷键行为

`Alt+Shift+T` 采用上下文行为：

| 当前状态 | 行为 |
| --- | --- |
| 存在有效选区 | 翻译选区 |
| 没有选区 | 打开扩展设置页 |
| 当前页面禁止扩展注入 | 打开扩展设置页 |
| 普通网页功能关闭 | 打开扩展设置页 |

这样保留了快捷翻译能力，也使快捷键可以稳定召回设置入口。

## 3. 浮动按钮

- 尺寸从 30 像素调整为 36 像素，提高可点击性。
- 使用紫色渐变、白色描边、柔和阴影和小型星光标记。
- 增加 hover、active 和键盘 focus 状态。
- 保持单字符“译”，避免在正文附近占用过多空间。
- 没有有效选区或选区被取消后，自动移除浮动按钮。
- 浮动按钮与翻译结果卡片使用独立状态，选区取消不会误关已经显示的结果。

## 4. 结果卡片

- 增大圆角和内容间距。
- 使用顶部渐变强调线。
- 改善操作按钮层级和 hover 状态。
- 保留 Shadow DOM 隔离与纯文本渲染。
- 保持明暗主题适配。

## 5. 设置页

- 新增品牌 Hero、版本标识和快捷键行为说明。
- 使用更清晰的分组、间距、输入框焦点和状态提示。
- 保存按钮采用主要操作样式，危险操作与普通操作分层。
- 在窄屏下切换为单列布局。
- 不引入远程字体、图片或 UI 框架，保持扩展包轻量和离线可用。

## 6. P&I Lab 品牌与主题

- 使用 `pi_logo.png` 作为扩展工具栏图标、网页浮动按钮和结果卡片标记。
- 使用 `team_logo.png` 在设置页标识 “Developed by P&I Lab”。
- 两份 Logo 作为本地资源随扩展打包，不从远程服务器加载。
- 网页浮层优先读取页面根元素/正文的主题标记与背景亮度，再回退到系统配色偏好。
- 深色网页中对 Pi Logo 使用高对比度反色处理；浅色网页保持原始深蓝品牌色。
- 设置页通过 `prefers-color-scheme` 跟随 Edge/操作系统的明暗主题。
