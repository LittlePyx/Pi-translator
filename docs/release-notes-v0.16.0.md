# Pi Translator v0.16.0

状态：更新包准备中；本轮不创建 GitHub Release、不提交 Edge 商店审核。

## 科研阅读与资料管理

- PDF 论文题名、署名和出版信息依据本地来源证据分层展示；有唯一可靠目标的公式、图、表与章节引用可以跳转，并返回原阅读位置。
- 本机文档库支持筛选、全文搜索、固定、容量明细、备份和续读。PDF 与网页的摘录及笔记可以统一整理，带出处复制和导出。
- 跨论文复用仅提供已确认术语，展示原始来源和目标语言，须逐条选择并人工确认。来源变化、同名冲突或容量不足时拒绝保存，不自动改写既有译文、公式、人工修正或本文约定。
- PDF 全文增加单段试译、请求上限、已报告用量与自填单价估算、待核对清单、校订预览和有限历史。金额不是服务商账单，未报告的用量、图像与 OCR 费用仍可能未知。

## PDF 可靠性与界面

- 完善多栏及跨页段落、通栏图注、完整图表与表格对象、公式来源编号、数学字体线索和分页导出；明确区分成功译文、待核对草稿及保留原文。
- 用户确认开始的 PDF 全文任务可在后台继续；暂停、停止和范围控制继续有效。文字预览不发送内容，扫描页与图像只按已确认任务的授权范围处理。
- 公式与原文对应检查、回显和输出截断提示继续保留，不以自动反复请求代替核对。人工校订的数学片段保持只读，失败重译保留旧结果。
- 统一简洁的浅色、深色与窄屏界面；短窗口菜单在内容或布局变化后重新定位，复制与导出操作保持可达。

## 数据与权限

相较已发布的 0.15.0 ZIP，增加 `offscreen` 权限，用于用户明确启动的 PDF 后台队列；隐藏文档只运行随包代码，在授权范围内本地渲染，不自动启动翻译或 OCR。原有必要网站权限与可选网站范围不变。不新增发布方服务或云同步。API 请求直接发送到用户配置的服务。显式保存的网页摘录、PDF 标记、笔记及术语来源保存在本机，并可包含用户确认的标题、网址、页码或本地文件名；仅在主动复制或导出备份时离开本机。术语约束只发送词条与译法，不附来源记录。完整规则见 [隐私政策](../PRIVACY.md)。

升级不会主动清空旧译文；取消更新时自动删除旧收藏记录的行为，不恢复已撤下的收藏界面。原 PDF 应继续保留；文档库备份只包含当前支持的已保存资料，不包含历史收藏键，也不能替代原文件。会话存储遵循浏览器生命周期，不承诺关闭 Edge 后保留仅存在于会话中的内容。

## 商店更新说明

中文：新增科研引用定位、统一摘录笔记、本机文档库管理与带来源和人工确认的跨论文术语复用。完善 PDF 图表、公式编号、数学字体、校订保护和导出，优化窄屏菜单与明暗主题。保留旧译文和人工修正，数据继续由用户在本机管理。

English: Research reading now includes source-linked PDF references, unified excerpts and notes, local library management, and confirmed terminology reuse with provenance. PDF layout, formula labels, correction safeguards, exports, and narrow-window menus are improved. Existing translations and manual edits remain under the user's control.
