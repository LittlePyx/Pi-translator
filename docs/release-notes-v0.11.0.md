# Pi Translator v0.11.0

本版本聚焦翻译任务的可恢复性、可修正性与状态一致性，同时保持结果界面清晰简洁。

## 主要更新

- 翻译因网络、超时或服务商错误中断时，会保留已收到的部分译文，并按错误类型提供复制、重试或定向检查设置。
- API Key、模型、域名权限或视觉配置需要修复时，可从错误界面直达对应设置；保存成功后返回原标签页，并只在不会重复计费的安全条件下继续任务。
- 普通网页、Overleaf、Pi PDF 与 Edge 原生 PDF 均可在本机修正译文；自然语言可编辑，LaTeX 片段保持锁定，保存与撤销不会再次调用翻译 API。
- 逐句对照支持只修正目标译句；用户明确填写的固定术语可独立保存到本文或全局，不会从整句修改中自动推断。
- 翻译结果、修正和撤销按标签页顺序提交，并校验当前结果与页面生命周期，防止旧请求、旧编辑器或延迟响应覆盖新译文。
- 快捷面板以紧凑状态行显示文字翻译与 PDF 图像配置，只读取本机状态，不会为了显示状态而调用 API。
- 翻译过程显示请求模型、接收译文、公式校验、整理结果和公式渲染等阶段；响应较慢时提供明确但克制的等待提示。
- 流式译文默认跟随最新内容，用户向上滚动阅读时保持当前位置；网页浮层与 Edge PDF 侧栏使用统一、易读的完成耗时。
- 本地诊断增加不含用户内容的阶段耗时摘要，便于区分接口、校验、提交、维护与公式渲染瓶颈。

## 安装

1. 下载 `tex-selection-translator-0.11.0-edge.zip` 并解压。
2. 在 Edge 打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压后的文件夹。
5. 在设置页配置文字翻译 API；需要扫描 PDF 或公式图像识别时，再配置支持图片输入的视觉 API。

## 隐私与安全

- 本版本未新增扩展权限；安装包不包含 API Key、审核凭证、PDF 正文或截图。
- 设置修复只保存一次性不透明票据及标签页路由，票据不包含选区、译文、页面 URL 或截图。
- 手工修正在本机完成；只有用户明确保存的术语会在后续翻译时作为约束发送到所配置的 API。
- 本地性能摘要只记录固定阶段的耗时数值，不记录 API 地址、模型、选区、译文、页面地址、公式或网站名称。
- PDF.js、KaTeX 与所有可执行代码均随扩展打包，不加载远程代码。
