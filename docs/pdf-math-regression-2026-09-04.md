## 修复与检查

| 问题 | 修改 | 本地与 Edge 结果 |
| --- | --- | --- |
| 根号单独成块，高亮只有一小块 | 先确定常规字号基线，再归属小字号上下标；根号跟随其被开方项 | 第 3 页没有独立根号任务，整段原文高亮一致 |
| argmin 下方 X 混进下一段 | 用优化算子的横向范围关联下方约束变量 | 下一段以 `Eq. (8)` 开始，选框不包含式 (9) |
| 选框下缘贴字、切字 | 使用 PDF 字体 descent 扩展可见字形边界，同时限制在相邻行之间 | 查看真实裁剪图，段尾完整，未扩入下一段 |
| 式 (15)、(16)、(17) 被当作表格/代码 | 识别函数式、变量乘积和右侧编号；归并重叠公式碎片 | 第 5 页没有表格/代码误判，编号各只有一个请求所属块 |
| `p = 4…β = 16` 在末尾重复 | 不把含自然语言的赋值句判为代码；跨中断合并截图时保留独立对象边界 | 原句只属于 Implementation Details 段，没有独立尾块 |
| 纯文本公式和 LaTeX 重复 | 仅在保守的字面对应可确认时原位替换；清理相邻的等价副本；不确定时不盲目追加 | 模拟原始响应经过真实扩展处理后，只渲染一份式 (17) |
| 编号掉到公式下面 | 补齐 PDF 阅读面板的编号公式布局 | Edge 宽/窄窗口检查通过，编号在右侧 |

修复不改变视觉授权边界，不自动发送图片，不增加隐式模型重试。普通划词、扫描页 OCR、范围预览和原文保护规则保持不变。

