# Pi Translator 广告文案

## 主文案

### 划词即译，就在当前页

复制、切换页面、粘贴、再切回来——网页翻译不该这么麻烦。

Pi Translator 是由 P&I Lab 开发的 Microsoft Edge 网页划词翻译扩展。在 Overleaf 或普通网站中选中文字，即可直接在当前页面查看翻译结果。

- Overleaf 与普通网站都能使用
- 支持浮动按钮、右键菜单和快捷键
- 使用自己的 API Key
- 支持多种目标语言快速切换
- 翻译卡片可拖动、复制和重新翻译
- 支持完整译文与逐句对照切换
- 当前标签页最近翻译可随时上下查看或清空
- 可固定为连续翻译侧栏，之后直接划词即可自动更新译文
- 支持多组兼容 API 配置和会话缓存
- 页面明暗主题自动适配
- 最近记录仅保留在浏览器会话中，不使用广告、分析或遥测

使用前需要准备自己的 API Key。

## 群聊短版

我做了一个可以在 Overleaf 和普通网站中使用的 Edge 网页划词翻译扩展：Pi Translator。

在网页中选中文字，就能直接显示翻译结果，不需要在原页面和翻译网站之间反复复制粘贴。支持浮动按钮、右键菜单和快捷键，翻译结果卡片还可以拖动、复制和重新翻译。

扩展使用你自己的兼容 API，支持完整译文、逐句对照和当前标签页最近翻译切换；会话记录也可以随时清空。
