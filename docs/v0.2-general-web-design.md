# Pi Translator v0.2：普通网页与设置扩展设计

> 状态：已实现
>
> 日期：2026-07-23
> 平台：Microsoft Edge / Manifest V3

## 1. 目标

v0.2 在保留 Overleaf LaTeX 翻译体验的基础上，增加普通网页翻译，并让用户控制模型、翻译偏好和网页权限。

设计目标：

- 普通网页默认采用按需权限，不在安装时要求读取所有网站。
- Overleaf 保持原有静态内容脚本和浮动按钮体验。
- 只有用户主动选择自动划词模式时才申请长期网站权限。
- DeepSeek 仍是当前服务商，但模型名称可以预设或自定义。
- 普通文本不强制经过 LaTeX 保护，技术内容可以自动识别。

## 2. 页面范围模式

| 模式 | 普通网页右键/快捷键 | 普通网页浮动按钮 | 权限 |
| --- | --- | --- | --- |
| 仅 Overleaf | 否 | 否 | 仅 Overleaf |
| 按需翻译 | 是 | 否 | `activeTab` 临时权限 |
| 指定网站 | 是 | 仅白名单网站 | 用户保存时申请指定域名 |
| 所有网站 | 是 | 是 | 用户保存时申请 HTTP/HTTPS 网站权限 |

Overleaf 项目页始终由专用静态内容脚本处理，通用动态内容脚本会排除该路径，避免重复注入。

## 3. 内容脚本策略

### 3.1 Overleaf

`entrypoints/overleaf.content.ts` 静态匹配：

```text
https://www.overleaf.com/project/*
```

它负责监听选区、显示浮动按钮以及接收右键菜单和快捷键消息。

### 3.2 普通网页按需注入

用户通过右键菜单或快捷键触发时，后台借助 `activeTab` 和 `scripting.executeScript` 注入：

```text
/content-scripts/general.js
```

该路径不需要安装时的全站权限。

### 3.3 自动注入

指定网站或所有网站模式下，设置页先使用 `permissions.request` 请求可选网站权限。后台随后使用 `scripting.registerContentScripts` 注册通用脚本。

动态注册在以下情况重新同步：

- 扩展安装或浏览器启动。
- 设置发生变化。

所有同步请求通过串行任务队列执行。注册前先查询并注销同 ID 的旧脚本，避免扩展启动、设置变化等事件同时触发时出现重复脚本 ID。

## 4. 设置模型

v0.2 使用 `schemaVersion: 2`，在读取旧设置时用默认值补齐新增字段。

```ts
interface ExtensionSettingsV2 {
  schemaVersion: 2;
  provider: 'deepseek';
  model: string;
  sourceLanguage: 'auto' | string;
  targetLanguage: string;
  style: 'academic' | 'general' | 'literal';
  contentMode: 'auto' | 'plain' | 'latex';
  apiKeyStorage: 'session' | 'local';
  showFloatingButtonOnOverleaf: boolean;
  hideFloatingButtonForTargetLanguage: boolean;
  generalPageMode: 'off' | 'on-demand' | 'allowlist' | 'all-sites';
  siteAllowlist: string[];
  enableContextMenu: boolean;
}
```

设置页提供 DeepSeek 模型预设，同时保留自定义模型名称，避免模型列表变化导致扩展必须发版。

## 5. 内容模式

- `plain`：直接翻译，不运行 LaTeX 保护器。
- `latex`：始终保护 LaTeX 片段和占位符。
- `auto`：Overleaf 项目页始终采用 LaTeX；普通网页根据常见命令、公式和环境标记检测。

无论内容模式如何，网页只接收纯文本渲染结果，不使用 `innerHTML`。

## 6. 安全与隐私

- API Key 仅由后台和设置页读取。
- 普通网页内容脚本只能提交用户主动选择的文本。
- 默认页面范围为按需翻译。
- 自动注入权限由用户在保存设置时显式授权。
- 切换到“按需翻译”或“仅 Overleaf”时停止普通网页自动注入；已授予权限由用户在 Edge 扩展详情页管理。
- 不保存翻译历史，不自动替换原文。
- 浏览器内部页面和禁止脚本注入的页面视为不支持页面。

## 7. 验证

自动检查包括：

- TypeScript 类型检查。
- LaTeX 保护器、提示词、响应解析器和 DeepSeek 请求测试。
- 内容模式判断测试。
- 域名规范化、白名单和匹配模式测试。
- Edge MV3 生产构建。
- 最终 Manifest 检查：普通网页权限必须位于 `optional_host_permissions`，静态 `content_scripts` 只能包含 Overleaf。

人工验证建议：

1. 重新加载扩展并刷新 Overleaf，确认原功能没有回归。
2. 在普通网页选择文本，通过右键菜单翻译。
3. 在普通网页选择文本，通过快捷键翻译。
4. 切换指定网站模式，确认 Edge 出现权限请求且刷新后显示浮动按钮。
5. 切换回按需翻译，确认普通网页不再自动显示浮动按钮。
