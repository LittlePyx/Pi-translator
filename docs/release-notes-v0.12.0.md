# Pi Translator v0.12.0

本版本让论文翻译中的历史、版本、术语与待核对事项更容易看懂和找回，同时继续收紧窄屏、长内容与 PDF 场景下的交互细节。

## 主要更新

- 翻译历史支持按原文、译文、网站和语言搜索，长时间使用后也能更快找回需要的记录。
- 最近三版译文会简要说明相对当前版本的增删与调整，不再需要仅凭时间猜测版本差异。
- 结果卡显示本次实际采用的固定术语及作用范围，方便确认术语约束是否真正生效。
- 本文术语可以标记为“待核对”，并与公式、OCR、模型调整等事项统一汇总；没有未处理事项时入口自动隐藏。
- 快捷面板会根据当前页面突出可执行操作，隐藏不相关控制，首次 API 设置和异常恢复也更直接。
- 网页卡片与 Edge PDF 侧栏改善长原文、长译文、修正、撤销和历史切换时的阅读位置与操作可达性。
- Pi PDF 的工具栏、区域队列、OCR 核对、标记导航和选框手柄进一步适配窄窗口与触控操作。
- 新增发布包一致性检查，确保 GitHub 下载的 ZIP 与当前 MV3 生产构建逐文件一致。

## 安装

1. 在本页底部下载 `tex-selection-translator-0.12.0-edge.zip` 并解压。
2. 在 Edge 打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压后的文件夹。
5. 在设置页配置自己的 OpenAI 兼容文字翻译 API；需要扫描 PDF 或公式图像识别时，再配置支持图片输入的视觉 API。

> Microsoft Edge 商店中的版本会按商店审核节奏更新；希望立即体验 v0.12.0，请使用本页 GitHub Release 的 ZIP。

## 隐私与安全

- 本版本未新增扩展权限，安装包不包含 API Key、审核凭证、PDF 正文或截图。
- 历史搜索、版本摘要、采用术语显示与本文待核对汇总均在本机完成，不会因此产生额外 API 请求。
- 只有用户主动触发翻译或图像识别时，选中的文字或确认的 PDF 区域才会发送到用户自行配置的 API。
- PDF.js、KaTeX 与所有可执行代码均随扩展打包，不加载远程代码。
