# Pi Translator v0.9.0

本版本集中增强 PDF 学术阅读、扫描页识别、公式保真和多 API 配置体验。

## 主要更新

- Pi PDF 支持本地与在线 PDF、文字划选、可调整框选、连续框选、阅读位置恢复和按文档隔离的翻译侧栏。
- 扫描页可通过用户确认的区域调用官方 Qwen OCR，生成仅存在于当前标签页的临时可选文字层。
- Edge 原生 PDF 中右键翻译会流式显示在按标签页隔离的原生侧边栏，并可将当前 PDF 交给 Pi PDF 打开。
- PDF 中含公式的划选严格使用视觉模型截图识别，不再悄悄降级为普通文本 API。
- 公式输出保留 LaTeX、编号和 `mathbb` 等数学字体语义；修复 `arg min` 约束跑到算子右侧、重复转义和长公式行内渲染问题。
- 长公式唯一编号固定在可横向滚动的公式主体右侧；复制与导出继续保留可编辑的原始 LaTeX。
- 文字翻译 API 与 PDF 图像 API 可使用不同配置；设置页提供官方 Qwen 快速配置，同时保留任意 OpenAI 兼容接口。
- Qwen / DashScope 视觉请求保留流式输出，但不发送可能触发服务端异常的强制 `response_format`。
- 新增本文术语、最近译句、轻标记、悬停译文和 Pi PDF 可选持久标记等轻量阅读功能。

## 安装

1. 下载 `tex-selection-translator-0.9.0-edge.zip` 并解压。
2. 在 Edge 打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压后的文件夹。
5. 在设置页配置文字翻译 API；需要扫描 PDF 或公式图像识别时，再配置支持图片输入的 Qwen 或其他视觉 API。

## 隐私与安全

- 安装包不包含 API Key、审核凭证、PDF 正文或截图。
- API Key 默认保存在浏览器会话中，只有用户明确选择后才持久保存到本机。
- 只发送用户主动选择的文字或最终确认的 PDF 局部截图；完整 PDF 和未确认区域不会上传。
- PDF、KaTeX 与所有可执行代码均随扩展打包，不加载远程代码。
