## 2. v0.14.0 已完成内容

### 网页翻译

- 普通网页、Overleaf、网页内固定侧栏和 Edge 浏览器侧栏均支持划词翻译。
- 网页区域框选始终走多模态流程，适用于渲染公式、图像、Canvas 和复杂混排；只有用户确认后才截图和发送，取消、移动或缩放选框不产生请求。
- 长网页提供轻量“译全文”入口。一次启动后自动翻译全部已识别正文，不要求用户滚动到每一段。
- 超过 100 个候选正文块时先显示本地确认页，提供段数、预计请求批次以及“全部正文 / 当前章节 / 从当前位置”预设；确认前零请求，应用预设后仍可逐段调整。
- 全文任务支持暂停、继续、停止、单段重试、阅读模式切换、刷新恢复、结果导出和可选本机保留。
- 公式处理已覆盖 KaTeX、MathJax 和 MathML。能提取 TeX 的内联公式随文字请求保护和校验；不能提取的视觉公式保留原网页内容，并提供低干扰的“框选识别”。

### PDF 翻译

- Pi PDF 顶部提供“译全文”。首次只在本地读取文字层、整理阅读顺序并预览范围，确认后才调用接口。
- 支持整篇、当前页和自定义页码；存在明确标题时才显示跳过参考文献或附录的选项，默认不自动排除。
- 译文按页组织，支持暂停、继续、停止、单段重试、返回原文、会话恢复和重新翻译。
- 没有文字层的扫描页只计数，不会被全文任务自动截图；必须由用户明确启动 OCR，并可中途停止。
- 支持纯译文 Markdown、双语 Markdown 和可打印 HTML 导出，以及匿名、本机、可管理的译文保留。

### 界面与交互

- 网页全文控制条、Edge 侧栏和 PDF 译文面板已经统一为更轻量、清爽的视觉层级。
- 网页框选十字准星提高了对比度，遮罩降低；选框支持鼠标和键盘调整。
- 网页内固定侧栏可能遮挡正文时会提示用户按需改用 Edge 浏览器侧栏，但不强制切换。
- 所有主动发送视觉内容的入口都必须先显示明确确认，不允许后台自动截图。

## 3. 已确定的产品规则

后续修改不得无意改变以下规则：

1. 普通网页的自动划词入口应避免打扰阅读。高置信度中文、目标语言文本、纯代码或代码式选区可以不显示浮动按钮。
2. 用户固定侧栏后代表明确的连续翻译意图。此时混合了自然语言和少量代码的选区仍应翻译，不能因为包含代码就整段跳过。
3. 普通划词使用文字接口；用户主动“框选网页”则使用多模态接口。不要根据框内是否碰巧提取到文字而偷偷降级为普通文字翻译。
4. 网页正文和 PDF 全文翻译都必须先保护公式、代码、表单及未成功内容，不能为了“只看译文”造成信息消失。
5. 扫描 PDF 的 OCR、网页截图和区域视觉识别都必须由用户明确触发和确认。
6. 全文翻译的本地预览、范围选择、取消和显示模式切换不得产生额外 API 请求。
7. 不自动替换网页、Overleaf 或 PDF 原文；翻译结果作为可撤销、可关闭的辅助阅读层存在。
8. 不引入 Pi 账号或自有翻译后端。产品继续采用用户自备 OpenAI 兼容 API Key 的模式。

## 5. 当前唯一推荐动作

不要继续叠加新功能。先把最终 ZIP 安装到真实 Edge，按 `docs/release-checklist.md` 完成最短实机验收：

1. 普通网页划词翻译。
2. 普通网页框选渲染公式，确认走多模态并成功返回。
3. 超过 100 段的网页先出现零请求确认，三个范围预设和逐段调整正常，确认后全文完成。
4. 普通文字 PDF 的全文预览、页码范围、暂停/继续、返回原文和导出正常。
5. 扫描 PDF 不自动 OCR；明确启动后才发送页面图像。

如发现问题，只修复能在最终 ZIP 中复现的阻塞项，然后重新执行发布门禁并生成新哈希。实机验收全部通过后，仍需等待用户明确授权，才能推送、创建 tag、GitHub Release 或提交 Edge 商店。

## 7. 关键目录

- `core/content/`：普通网页划词、网页全文翻译和页面交互。
- `core/translation/`：翻译请求、批处理、会话、导出和正文结构逻辑。
- `entrypoints/background.ts`：扩展后台消息、标签页状态和 API 调度。
- `entrypoints/sidepanel/`：Edge 浏览器侧栏。
- `entrypoints/pdf/`：Pi PDF 阅读器和 PDF 全文翻译界面。
- `tests/`：单元测试。
- `tests/e2e/`：真实 Edge 扩展端到端测试。
- `tools/check-release-consistency.mjs`：版本、ZIP、Manifest 和逐文件一致性门禁。
- `store-assets/ads/`：广告素材；当前不属于代码提交范围。
