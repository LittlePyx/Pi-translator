# Pi Translator 商店文案（简体中文）

## 名称

Pi Translator

## 简短说明

在 Overleaf 和普通网页中翻译选中文本，支持 DeepSeek、自定义学术术语表与 LaTeX 结构保护。

## 完整说明

Pi Translator 是由 P&I Lab 开发的 Microsoft Edge 划词翻译扩展，面向论文阅读、学术写作和日常网页浏览。

在 Overleaf 中选中 LaTeX 源文或自然语言内容后，扩展会显示轻量浮动按钮；在普通网页中，可使用右键菜单或 Alt+Shift+T 快捷键按需翻译。翻译结果显示在可拖动的卡片中，可复制译文、同时复制原文与译文，或重新翻译。

主要功能：

- 使用用户自己的 DeepSeek API Key，自动读取该 Key 当前可用的模型，同时保留自定义模型名称。
- 支持自动识别源语言，并可快速切换简体中文、英语、日语、德语和法语等目标语言。
- 提供学术、通用和直译三种翻译风格。
- 自动识别普通文本与 LaTeX 内容，保护命令、数学公式、引用和其他结构，降低翻译破坏源码的风险。
- 支持最多 100 条本地学术术语映射，让论文中的关键术语保持一致。
- 工具栏快速面板可切换目标语言，或临时暂停当前网站的自动划词按钮。
- 普通网页默认采用按需访问模式，不要求所有网站的长期权限；用户也可自行选择指定网站或全部网站自动启用。
- 浮动按钮和结果卡片适配网页的明暗主题，结果卡片支持鼠标、触控笔和触摸拖动。
- 不保存翻译历史，不使用广告、分析或遥测服务。

只有用户主动触发翻译的选中文本，以及用户配置且与翻译相关的术语映射，才会通过 HTTPS 直接发送到 DeepSeek API。API Key 不会注入网页，也不会经过 P&I Lab 的服务器。使用扩展需要用户自行准备 DeepSeek API Key，相关 API 调用可能由 DeepSeek 按其规则计费。
