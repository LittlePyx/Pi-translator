# Pi Translator 商店文案（简体中文）

## 名称

Pi Translator

## 简短说明

在 Overleaf、PDF 和普通网页中翻译选中文本，支持连续侧栏、流式翻译与 LaTeX 保护。

## 完整说明

Pi Translator 是由 P&I Lab 开发的 Microsoft Edge 划词翻译扩展。它可以在普通网页、Overleaf 和 PDF 文档中翻译用户主动选中的内容，让阅读外文网页、论文和技术资料时不必频繁复制、切换页面。

使用方式很简单：选择翻译服务商，填写自己的 API Key，连接并选择可用模型；随后在页面中选中文字，通过浮动按钮、右键菜单或快捷键即可获得译文。扩展不绑定单一模型服务，支持常用服务商预设，也支持用户填写 OpenAI Chat Completions 兼容的自定义 API 地址和模型。

核心功能：

- 网页与 Overleaf 划词翻译：选中单词、句子或段落，在当前页面直接查看译文；结果卡片可移动，也可固定为连续翻译侧栏。
- PDF 阅读支持：在 Edge 原生 PDF 阅读器中通过右键菜单翻译，结果流式显示在当前 PDF 专属侧边栏，不跳转页面、不替换原阅读器。
- Pi PDF 阅读器：支持本地和在线 PDF、跨行文本选择与阅读位置恢复。对于扫描版或文字不清晰的 PDF，可在用户框选并确认后调用自选视觉模型识别和翻译局部区域。
- 流式结果与逐句对照：兼容模型可边生成边显示译文，并可在完整译文和逐句对照之间切换；支持复制、单句重译和最近翻译切换。
- 连续阅读体验：将结果固定到页面侧栏后，继续选择文字即可自动更新翻译；侧栏可收起、调整宽度和切换左右位置。
- LaTeX 友好：自动识别含公式或命令的内容，在翻译过程中保护 LaTeX 结构，并可将译文中的公式渲染显示或切回源码。
- 轻量标记：可为重要原句添加低干扰标记，悬停查看译文；Pi PDF 还可按文档保存、定位和整理标记笔记。
- 多语言与外观：支持自动识别源语言以及多种目标语言，翻译界面会适配网页的明暗主题。
- 灵活的 API 配置：可保存多组接口配置，自动读取当前 API Key 可用的模型；无法读取模型列表时也可以手动填写模型 ID。

隐私与数据：

Pi Translator 只在用户主动触发翻译时，才把选中的文本发送到用户配置的 API。PDF 框选图片只有在用户确认后才会发送，完整 PDF 不会上传，局部截图不会写入扩展存储。API Key 保存在 Microsoft Edge 扩展存储中，默认仅保留到当前浏览器会话结束；用户也可以自行选择本机持久保存并随时清除。

P&I Lab 不运营翻译中转服务器，不接收用户的 API Key、选中文本或翻译结果。扩展不包含广告，不使用分析、遥测或用户跟踪服务。第三方 API 的可用性、数据处理方式、费用和使用条款由用户选择的服务商决定。

使用 Pi Translator 的翻译功能需要用户自行准备兼容的 API Key。部分功能取决于所选接口和模型是否支持流式输出、图片输入或结构化结果。
