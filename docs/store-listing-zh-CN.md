# Pi Translator 商店文案（简体中文）

## 名称

Pi Translator

## 简短说明

在 Overleaf 和普通网页中翻译选中文本，支持连续侧栏、流式翻译、上下文辅助与本地收藏。

## 完整说明

Pi Translator 是由 P&I Lab 开发的 Microsoft Edge 划词翻译扩展，适合论文阅读、写作和日常网页浏览。

在 Overleaf 或普通网页中选中文字，通过浮动按钮、右键菜单或 Alt+Shift+T 即可翻译。结果显示在可拖动的轻量卡片中，不会自动替换原网页内容。

主要功能：

- 自行配置 API Base URL、API Key 和模型名称，可使用采用 OpenAI Chat Completions 兼容协议的翻译服务。
- 新安装提供三步设置向导，并可自动读取当前 API Key 可用的模型。
- 最多保存 6 组 API 配置，并可从工具栏快速切换。
- 自动读取当前 API Key 可用的模型，也可直接填写模型名称。
- 可按需运行低消耗兼容性诊断，检查接口鉴权、模型、结构化输出和逐句能力。
- 支持自动识别源语言，并可切换简体中文、英语、日语、德语和法语等目标语言。
- 完整译文与逐句对照即时切换；逐句原文直接来自本地选区。
- 可把结果固定为页面侧栏；固定后只需继续选中文字，侧栏便会自动更新翻译。侧栏支持收起、左右切换和宽度调整。
- 当前标签页最近 5、10 或 20 条翻译可上下切换、固定、删除或导出。
- 相同选区可使用会话缓存减少等待和重复 API 消耗；缓存可关闭或强制绕过。
- 兼容接口可流式显示普通文本译文，遇到限流或暂时性服务错误时自动退避重试。
- 长文本会在本机安全拆分并显示翻译进度；新选区会取消过时请求。
- 可选择所在句子或段落作为消歧上下文，默认关闭。
- 结果可主动收藏到本机，并按原文、译文或来源网站搜索。
- 连续翻译会跳过密码、验证码和支付字段，并可从侧栏暂停当前网站。
- 逐句对照支持联动高亮、单句复制和单句重新翻译。
- 自动识别普通文本与 LaTeX 内容，保护命令、公式和引用等结构。
- 工具栏快速面板可切换目标语言，或临时暂停当前网站的自动划词按钮。
- 普通网页默认按需访问；用户也可选择指定网站或全部网站自动启用。
- 浮动按钮和结果卡片自动适配网页的明暗主题，结果卡片支持拖动。
- 不使用广告、分析或遥测服务。
- 可安全导入、导出不含 API Key 的配置，并生成不含翻译正文和密钥的本地诊断报告。

只有用户主动触发翻译，或主动固定连续翻译侧栏后完成的新选区，才会直接发送到用户配置的 API。API Key 不会注入网页，也不会经过 P&I Lab 的服务器。第三方 API 的使用条件、数据处理方式和费用由用户选择的服务商决定。
