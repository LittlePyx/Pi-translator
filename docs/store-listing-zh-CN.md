# Pi Translator 商店文案（简体中文）

## 名称

Pi Translator

## 简短说明

在 Overleaf、PDF 和普通网页中翻译选中文本，支持连续侧栏、流式翻译与 LaTeX 保护。

## 完整说明

Pi Translator 是由 P&I Lab 开发的 Microsoft Edge 划词翻译扩展，适合 PDF 论文阅读、Overleaf 写作和日常网页浏览。

在 Overleaf、PDF 或普通网页中选中文字，通过浮动按钮、右键菜单或 Alt+Shift+T 即可翻译。普通网页和 Pi PDF 使用轻量翻译卡片；Edge 原生 PDF 的右键译文流式显示在浏览器侧边栏，不会自动替换页面或切换阅读器。

主要功能：

- 自行配置 API Base URL、API Key 和模型名称，可使用采用 OpenAI Chat Completions 兼容协议的翻译服务。
- 内置轻量 PDF 阅读器，可打开本地或在线 PDF，支持单词、句子和跨行段落选择；也可在用户确认后将局部框选图片交给自选视觉模型识别并翻译，适用于扫描版或文字不清晰的 PDF；长论文按视口懒加载。
- Edge 原生 PDF 兼容模式：右键翻译并在当前 PDF 标签页专属的 Edge 侧边栏查看流式译文；切换网页时自动隐藏，选择“用 Pi 打开”时会继承当前 PDF 并收起原侧边栏。
- 新安装提供三步设置向导，并可自动读取当前 API Key 可用的模型。
- 最多保存 6 组 API 配置，并可从工具栏快速切换。
- 自动读取当前 API Key 可用的模型，也可直接填写模型名称。
- 可按需运行低消耗兼容性诊断，检查接口鉴权、模型、结构化输出和逐句能力。
- 支持自动识别源语言，并可切换简体中文、英语、日语、德语和法语等目标语言。
- 完整译文与逐句对照即时切换；逐句原文直接来自本地选区。
- 可把结果固定为页面侧栏；固定后只需继续选中文字，侧栏便会自动更新翻译。侧栏支持收起、左右切换和宽度调整。
- 当前标签页最近 5、10 或 20 条翻译可通过卡片顶部按钮上下切换。
- 相同选区可使用会话缓存减少等待和重复 API 消耗；缓存可关闭或强制绕过。
- 可对整个选区或逐句对照中的某一句进行轻标记：原文仅出现克制的低透明度底色，悬停即可查看对应译文；Pi PDF 可在清爽的本文导航器中按页码查看原文与译文、返回原句、复制或删除单条，也可把全部标记笔记复制为 Markdown。标记默认随页面关闭而清除；Pi PDF 可按文档单独开启本机保存，并只在页码、原文和前后文可靠匹配时恢复着色。普通网页和 Edge 原生 PDF 不持久保存标记。
- 兼容接口可流式显示普通文本译文，并校验流式响应是否完整；只有明确的限流或服务端错误最多自动重试一次，避免超时或断网造成重复请求。
- 长文本会在本机安全拆分并显示翻译进度；失败后可从首个未完成分段继续，新选区会取消过时请求。
- PDF 选区在本机移除软连字符并保留可见硬连字符；没有可靠排版几何信息时保留原始换行，扩展不猜测或重排双栏顺序。
- 扩展会话内记住当前接口与模型的兼容能力，避免反复尝试已确认不支持的流式或 JSON 参数。
- 可选择所在句子或段落作为消歧上下文，默认关闭。
- 连续翻译会跳过密码、验证码和支付字段，并可从侧栏暂停本网站的连续翻译。
- 逐句对照支持联动高亮、单句复制和单句重新翻译。
- 自动识别普通文本与 LaTeX 内容，保护命令、公式和引用等结构。
- 翻译完成后可自动渲染行内与独立 LaTeX 公式，并可随时切回可编辑源码；复制的仍是原始 LaTeX。
- 工具栏快速面板可切换目标语言，或临时暂停本网站的自动划词按钮。
- 普通网页默认按需访问；用户也可选择指定网站或全部网站自动启用。
- 浮动按钮和结果卡片自动适配网页的明暗主题，结果卡片支持拖动。
- 不使用广告、分析或遥测服务。
- 可安全导入、导出不含 API Key 的配置，并生成不含翻译正文和密钥的本地诊断报告。

只有用户主动触发翻译、主动固定连续翻译侧栏后完成的新选区，或在 Pi PDF 中框选局部图片并再次确认后，相关文本或局部图片才会直接发送到用户配置的 API。完整 PDF 不会上传，局部截图不会写入扩展存储。API Key 不会注入网页，也不会经过 P&I Lab 的服务器。第三方 API 的使用条件、数据处理方式和费用由用户选择的服务商决定。
