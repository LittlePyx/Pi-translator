# PDF 含公式正文的分级回退修复

## 问题与处理

HATNet 第 5 页公式 (16)、(17) 的上下文正文与公式作为一个视觉块处理。此前视觉结果缺少公式元数据或未通过结构校验时，整块译文被替换为提取的英文，界面仍显示“已保留原式”。

本次统一前台与后台结果处理策略：

1. 已通过原有校验的结果保持不变，不放宽公式校验。
2. 公式边界闭合、能明确分离正文、正文符合目标语言且未残留未标记数学表达式时，保留正文译文；尚未核对的公式用“公式见原文”标记。缺少公式的正文仍有整段待核对提示。
3. 中文正文与未闭合 LaTeX、普通文本公式或希腊字母无法安全分离时，保留模型原样返回的“待核对译文”，不再整段丢弃。此类草稿在阅读器、HTML 与原页对照 PDF 中不执行公式渲染，明确标注非最终结果，数学内容以原 PDF 为准。仅有公式、空结果、原文回显或没有足够目标语言正文时，保留原文并说明具体原因。
4. “查看原因与原文截图”按需在本地渲染完整源区域（含跨栏区域），默认收起；不额外请求模型。截图不是重建的公式，也不把模型生成的可疑 LaTeX 当作正确原式。
5. 单段重试须由用户点击；不恢复其他暂停段落的队列。失败保留先前结果，成功清除该段待核对状态。
6. 会话/本机保留保存待核对状态，不保存截图。旧版与原文相同的含公式结果明确标注，避免当作成功中文译文。阅读、Markdown、HTML 和原页对照 PDF 均保留核对提示；图文双语 Markdown 附上本地完整原文截图。
7. 待核对的占位提示不作为上一段译文发送给后续模型请求；原文连续上下文仍保留。
8. 正文恢复使用独立的语言证据判断，允许学术术语和数学符号混排；不修改普通网页自动划词的高置信度目标语言过滤。数学命令名不作为英文正文计数。视觉提示明确要求公式不确定时仍完整翻译前后正文，不隐藏增加任何修复请求。

## 验证范围

- 新增分级回退单元用例：公式 (16)/(17)、行内/独立公式、缺失公式元数据、未闭合边界、未标记数学表达式、纯公式、原文回显与空返回，以及长英文术语、长 LaTeX、未标记维度和希腊字母混排。
- 新增会话和本机恢复用例，验证状态保留及重试成功后清除。
- 隔离 Edge 回归：可分离正文和不可分离草稿两条路径，原文截图展开、三种下载格式、同一文件重开、窄屏、单段重试失败保留与重试成功；HTML 导出与原页对照 PDF 打印预览不把草稿中的可疑公式渲染成数学排版。
- 用户本地 HATNet 论文：第 3-5 页 20 个块，7 个问题区域的点击定位；公式 (16)/(17) 注入不一致的模拟公式响应，验证两段正文均保留、完整原文截图可展开。

所有测试中的模型响应均为本地模拟，不代表真实 QWEN 输出或语义准确性验收；没有发送论文到外部模型。结构检查不能证明模型译文语义完全正确，且无法安全分离的结果仍需用户核对或重试。
