## 问题与修改

此前模型分别在识别原文、译文及公式列表中重复生成 LaTeX，字体、上下标、空格或符号出现差异后，整段校验失败，再把所有数学片段替换成“公式见原文”。另有按相同数量依次替换公式的旧兼容逻辑，可能掩盖真正的符号错误。

1. 含公式 PDF 段落改用 `refs-v1` 输出：每个数学片段只登记一份 LaTeX，原文和译文按编号引用。编号随语义移动，可调整译文语序，不依赖第几个公式的位置。其他框选／图表接口不强制采用此合同。
2. 逐项检查格式、结构、引用次数、缺项、重复与模型不确定标记。单项失败不清空其他项；无可靠对应的数学内容不当成已核对结果。
3. 只对旧结果的确切数学拼写匹配做局部恢复，不再因数量相同就替换不同变量、加减号、字体或顺序。
4. 问题项在正文内显示短编号核对入口，并默认展开完整源段落截图；没有可靠的单公式坐标时不猜测裁剪。其余公式正常渲染，显式区分行内与独立公式。注册模板的普通文字不解释为 LaTeX 或 HTML。
5. 公式齐全但正文仍为原文或被省略时显示失败原因；流式过程不暴露内部模板编号。仍使用原来授权的视觉模型，不增设隐藏纠错请求。
6. 会话／显式本地保留只存公式登记、译文模板与源引用顺序，不额外保存原文正文或图像。恢复重新检查引用关系；重试失败保留先前结果，成功替换相应段。
7. 阅读器、Markdown、带原页图 HTML 和对照打印页使用同一份登记。可用公式保留，问题项及核对提示保留；导出、切换显示和本地截图零模型请求。

## 使用与边界

重新加载新版扩展并重新打开 PDF。已经保存的旧降级结果不会自动重译；对受影响段落点击“重试本段”，或明确重新翻译所选范围，才使用新登记合同。不会因此清空整篇结果或自动发送图像。

单份登记消除的是多次生成不一致及全段降级；它不能证明 LaTeX 与像素语义完全相同。真实模型仍可能看错字体、上下标或漏掉表达式。原 PDF 是最终依据，尚需用户在其已配置模型上对原问题段落进行一次明确启动的实机验收，不能宣称所有公式完全正确。
