Test steps:
1. Install the extension. Settings opens automatically. Enter the text values above, connect, and save.
2. On any public HTTPS article, select an English sentence, right-click, and choose “使用 Pi Translator 翻译选中文本”. Verify streaming, copy/correction, and continuous sidebar actions.
3. Open either the in-page fixed translation sidebar or the Edge browser side panel and click the prominent “框选网页” action at its top (the toolbar popup also keeps “框选网页区域”). Draw over visible article text or a rendered formula. The confirmation states that the selected visible region will be sent to the configured multimodal model. Nothing is captured or sent until the confirmation button is clicked. Both sidebars keep the action available while translating or viewing a result; pressing Escape during selection restores the in-page sidebar without a request. From the result menu, “调整区域” restores the box while “重新框选” starts empty; neither makes a request until reconfirmed.
4. Optional with the image credentials: draw over an image or Canvas. Only the selected visible region is captured, and only after the confirmation button is clicked. Full-page, auto-scroll, and continuous capture are unavailable. Regions containing password, verification-code, or payment fields are blocked.
5. From a result, open the Edge browser side panel and select more page text. Its recent-result arrows and “全文 / 逐句” view switch do not make another API request.
6. On a sufficiently long foreign-language article, open Pi Translator and use “译全文 · N 段”. A page with more than 100 eligible blocks first shows the detected count and estimated batch requests without sending content. “调整范围” offers all body text, the current explicit H1–H4 section, or content from the current reading position; applying remains optional. After confirmation, verify that bilingual translations complete below the main prose while navigation, forms, code blocks, and independent formulas stay unchanged. The page control can switch among bilingual, translated-only, and original-only display without another API request.
7. Optional: open “PDF 阅读器”, load a local PDF, and click “译全文”. The first step only previews locally detected paragraphs. Confirm a whole-document, current-page, or custom-page range, then verify page-grouped translations, pause/resume, source navigation, and export. Pages without a text layer are only counted; page images are sent only after the separate OCR action is explicitly started. Selectable text does not require image capability.
8. Optional: open a PDF directly in Edge, select text, and use the same context-menu command. The result appears in Edge’s side panel.

Requests go directly to the configured provider. Keys stay in extension storage, are not bundled, and are not exposed to webpages. Screenshots are not stored. No remote code is loaded.
