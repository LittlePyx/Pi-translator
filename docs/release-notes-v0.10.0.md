# Pi Translator v0.10.0

本版本继续完善 PDF 学术阅读体验，重点降低公式与扫描内容的误识别成本，并加入轻量的识别结果核对流程。

## 主要更新

- Pi PDF 对拆散公式、优化算子、控制字符、重叠数字和表格叠印文字采用更严格的视觉识别判定，同时避免把普通 URL 查询参数误判为公式。
- 公式截图尊重用户实际框选范围，保留右侧编号但不擅自扩展到选区外正文；缺失的单个末尾行间公式可在本地安全补回。
- 新增“本文待核对”入口：只有公式校验或视觉识别存在不确定内容时才出现，可返回原区域、打开结果、重新识别或标记为已核对。
- 对同一 PDF 区域重新识别时，会替换会话缓存和本文记忆；干净的新结果自动移出待核对列表，已核对证据不会重复提醒。
- 新增紧凑的人工修改与模型调整流程，保留最近三版结果；失败后可安全重试，不需要重新选择原文。
- PDF 扫描页继续提供持久的“识别本页”入口，识别中可取消，换页、缩放或更换文档时同步终止请求。
- API Key、模型、域名授权、Qwen OCR 和本地诊断错误会跳转到对应设置项，并在设置页无法打开时提供当前界面反馈。
- 翻译卡片“更多”菜单按可用空间自动限高，修复较短侧栏或 PDF 画布底部操作难以点击的问题。
- 文档身份使用本机哈希隔离；待核对记录不保存截图或 API Key，也不会作为已确认的后续翻译参考。

## 安装

1. 下载 `tex-selection-translator-0.10.0-edge.zip` 并解压。
2. 在 Edge 打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压后的文件夹。
5. 在设置页配置文字翻译 API；需要扫描 PDF 或公式图像识别时，再配置支持图片输入的视觉 API。

## 隐私与安全

- 安装包不包含 API Key、审核凭证、PDF 正文或截图。
- API Key 默认保存在浏览器会话中，只有用户明确选择后才持久保存到本机。
- 只发送用户主动选择的文字或最终确认的 PDF 局部截图；完整 PDF 和未确认区域不会上传。
- PDF、KaTeX 与所有可执行代码均随扩展打包，不加载远程代码。
