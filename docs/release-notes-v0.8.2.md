# Pi Translator v0.8.2

这是面向 Microsoft Edge 商店重新审核的配置体验与发布资料更新。

## 主要更新

- API 设置简化为三步：选择服务商、填写 API Key、连接并自动配置。
- 自动读取当前 Key 可用的模型，推荐并验证文字模型。
- 在接口支持时自动检测 PDF 图片区域翻译能力；未检测到视觉模型时，普通文字翻译仍可正常使用。
- 保留自定义 OpenAI 兼容 API，服务商、接口地址和模型仍由用户控制。
- 设置页增加紧凑的连接能力摘要，避免堆叠额外卡片和标签。
- 更新商店 Logo、大小宣传图、权限说明、隐私披露及审核测试步骤。

## 安装

1. 下载 `tex-selection-translator-0.8.2-edge.zip` 并解压。
2. 在 Edge 打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压后的文件夹。
5. 在 Pi Translator 设置页选择服务商，填写自己的 API Key，然后点击“连接并自动配置”。

## 安全说明

- Release ZIP 不包含 API Key、测试凭证或私钥。
- 自动配置只连接用户选定的 API 域名，不会跨服务商尝试 API Key。
- API Key 默认只保存在浏览器会话中，可由用户选择是否保存在本机。
- 用户主动选择的文本或确认发送的 PDF 局部区域才会发送到其配置的翻译 API。
