# Pi Translator v0.6 连续翻译侧栏与稳定性设计

## 1. 设计原则

v0.6 采用渐进披露：默认浮动卡片只显示译文、视图切换和复制；历史管理、临时语言/风格、导出和重译集中在“更多”菜单。只有用户主动固定侧栏后才进入连续翻译模式。

## 2. 连续翻译侧栏

- 浮动卡片和工具栏快速面板均可打开侧栏；
- 固定后监听用户完成的新选区，经过 220 ms 防抖后自动翻译；
- 相同选区不会重复触发，目标语言选区仍沿用原有高置信度跳过规则；
- 收起后保留页面边缘窄标签，下一次选区会自动展开结果；
- 关闭侧栏立即退出连续模式；
- 支持左右位置、320–640 px 宽度和宽度记忆；
- 侧栏不改变网页 DOM 内容，也不自动读取未选择的正文。

## 3. 多 API 配置和诊断

最多保存 6 组 OpenAI 兼容 API 配置，每组包含名称、Base URL、模型和独立 API Key。工具栏面板可切换活动配置。保存时请求各 API 的具体 origin，并移除不再使用的旧 API origin 权限。

兼容性诊断由用户显式触发，使用固定短文本 `Hello.` 检查：

1. API origin 权限；
2. API Key 鉴权和模型列表；
3. Chat Completions；
4. JSON 结构化输出；
5. 逐句 ID 对齐。

接口返回纯文本或混合内容时，解析器尝试提取 JSON；仍无法结构化时降级为完整纯文本译文。HTTP 错误会保留经过长度限制的服务商错误信息。

## 4. 会话缓存和历史

缓存键包含文本、语言、风格、内容模式、API origin、模型和翻译约束，不包含 request ID。每个标签页最多缓存 20 条；重试操作可绕过缓存。缓存与历史都使用 `browser.storage.session`，标签页关闭或浏览器退出后删除。

历史数量可选 5、10 或 20 条，支持会话内固定、单条删除、清空和 Markdown 导出。记录只保存来源 hostname，不保存完整页面 URL。

## 5. 逐句交互

逐句原文仍由本地切分。鼠标或键盘聚焦某一行时，原文与译文整体联动高亮；宽侧栏自动改为左右对照。每句可独立复制或作为新请求重新翻译。

## 6. 隐私和费用控制

连续模式、诊断、缓存和历史均有明确的用户入口或开关。诊断会产生一次极小的 API 请求；连续模式只处理完成的选区；缓存用于避免相同请求重复计费。P&I Lab 仍不运营翻译中转服务器。
