# Pi Translator v0.7 稳定性、上下文与收藏设计

## 1. 设计目标

v0.7 在不增加主翻译卡常驻控件的前提下，提升连续翻译的可靠性、长文本体验和结果复用能力。高级入口继续集中在“•••”菜单和设置页折叠区域。

## 2. 请求生命周期

- 每个标签页最多保留一个活动翻译请求；新选区会主动取消旧请求。
- 单次请求超时为 30 秒。限流、网络错误和服务端暂时错误最多尝试 3 次，采用可中断的指数退避，并尊重合理范围内的 `Retry-After`。
- 普通文本优先请求 SSE 流式响应；接口不支持流式参数时自动回退到普通 Chat Completions。
- 流式界面更新限制为约 80 毫秒一次，避免消息洪泛。

## 3. 长文本

选区上限提升为 32,000 个字符。超过单次安全块大小后，本机优先在段落、句号、换行或空白边界拆分。每块独立保护 LaTeX、翻译并恢复结构，最后按顺序合并；侧栏显示当前块进度。

## 4. 上下文辅助

上下文默认关闭。用户可选择所在句子或所在段落，最多 2,000 个字符。提示词明确要求模型只使用上下文消歧，不得翻译、引用或总结上下文。缓存键包含上下文，避免错误复用。

## 5. 收藏与搜索

最近记录仍只在会话中保存。只有用户主动点击“收藏当前译文”时，结果才进入本机持久收藏，最多 100 条。收藏界面位于侧栏更多菜单，可搜索原文、译文和来源网站，并支持逐条删除。

## 6. 敏感字段与可访问性

连续翻译默认跳过密码、验证码、信用卡号和安全码等字段；手动翻译仍由用户决定。侧栏以轻量状态胶囊显示“自动翻译中”，支持键盘焦点、ARIA 标签、高对比焦点和 `prefers-reduced-motion`。

## 7. 接口预设

预设只填写 API Base URL 和建议模型，不包含或获取 API Key。当前提供 DeepSeek、OpenRouter 和本机 Ollama；用户始终可以改回自定义配置并读取实际可用模型。
