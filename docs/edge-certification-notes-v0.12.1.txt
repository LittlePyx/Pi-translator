Test steps:
1. Install the extension. Settings opens automatically. Enter the text values above, connect, and save.
2. On any public HTTPS article, select an English sentence, right-click, and choose “使用 Pi Translator 翻译选中文本”. Verify streaming, copy/correction, and continuous sidebar actions.
3. From a result, open the Edge browser side panel and select more page text. The independent panel updates without covering the page. Its arrows revisit recent results; “全文 / 逐句” changes views without another API call.
4. The popup checks the text API and actual Edge shortcut. If the suggested shortcut was not assigned, its link opens edge://extensions/shortcuts.
5. Optional: configure the vision values, open “PDF 阅读器”, load a local PDF, and translate selectable text or a confirmed image region. Selectable text does not require vision.
6. Optional: open a PDF directly in Edge, select text, and use the same context-menu command. The result appears in Edge’s side panel.

Requests go directly to the configured provider. Keys stay in extension storage, are not bundled, and are not exposed to webpages. History navigation, readiness checks, and PDF layout safeguards are local. No remote code is loaded.
