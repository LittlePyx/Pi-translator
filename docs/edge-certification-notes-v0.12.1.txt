Test steps:
1. Install the extension. The settings page opens automatically. Enter the text provider values above, select Connect, then save.
2. Open any public HTTPS article, select an English sentence, right-click, and choose “使用 Pi Translator 翻译选中文本”. Verify the streamed translation, copy/correction actions, and continuous sidebar.
3. From a completed result, open the Edge browser side panel. Select more text on the page; the independent panel updates without covering page content. Its arrows revisit recent results, and “全文 / 逐句” switches the result view without another API call.
4. The popup reports whether the text API and Edge shortcut are ready. If Edge did not assign the suggested shortcut because of a conflict, its link opens edge://extensions/shortcuts.
5. Optional PDF test: configure the vision values above, open “PDF 阅读器”, load a local PDF, then translate selectable text or a user-confirmed image region. Text-only PDF use does not require the vision API.
6. Optional native-PDF test: open a PDF directly in Edge, select text, and use the same context-menu command; the result appears in Edge’s side panel.

API requests go directly to the reviewer-selected provider. Keys are stored only in extension storage, are not bundled in the package, and are not exposed to webpages. Local history navigation, readiness checks, and PDF layout safeguards do not make API requests. The extension loads no remote code.
