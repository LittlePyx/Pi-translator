# Pi Translator v0.15.0

本版本在 v0.14.0 的网页正文双语阅读和网页区域框选基础上，完整加入网页与 PDF 全文翻译。长文章可以保留原文、逐段在下方显示译文；Pi PDF 可以先在本地预览整篇、调整页码范围，再批量生成按页组织的译文。面对文字、图像、图表、Canvas、扫描页、渲染公式或复杂混排时，也可以由用户明确圈出当前可见区域，交给多模态模型结合画面理解和翻译。普通划词仍使用文字接口，各入口不会暗中混用。

## 主要更新

- 网页“译全文”会在一次明确启动后完成全部已识别正文，不再要求读者滚到每一段。当前视口最多合并 2 段以便快速回填，后台正文最多合并 6 段以减少请求；模型按不可变段落 ID 分别返回译文，批次中单段漏回、格式异常或公式破坏只重试对应段，已成功内容不会重发。无限滚动新增正文、暂停、停止、刷新恢复和主动划词抢占继续按安全批次衔接。
- 超过 100 段的网页会先显示轻量确认，列出正文段数和预计批量请求次数；确认前不会调用翻译接口。进入“调整范围”后可选择“全部正文 / 当前章节 / 从当前位置”，其中章节只依据网页已有 `H1–H4` 层级，当前位置取阅读区上方约三分之一处；预设后仍可逐段微调，段数与请求估算实时更新。
- Pi PDF 顶部新增“译全文”：先在本地读取文字层、整理可信双栏阅读顺序、跳过多页重复页眉页脚并按版面拆分自然段，再由用户确认后批量翻译。开始前可选择整篇、当前页、自定义页码，并在存在明确标题时选择是否跳过参考文献或附录；译文按页排列，点击可返回原文位置。
- PDF 全文任务支持暂停、继续、停止、单段重试、会话恢复和重新翻译。没有文字层的扫描页只明确计数，不会自动截图；用户可显式启动逐页 OCR，并可随时停止。网页和 PDF 的完成结果均可复制或下载纯译文 Markdown、双语 Markdown 与可打印 HTML，也可选择仅在本机保留匿名文档指纹与译文，不保存原文、网址、PDF 文件或截图。
- 在长文章页打开 Pi Translator 后，网页右下角会出现可关闭的轻量“译全文 · N 段”入口，不必再到快捷面板或侧栏中寻找。默认按需模式只在用户明确打开 Pi 后激活当前标签页，不新增常驻网站权限。入口相对当前目标语言判断，只统计非目标语言的连续可翻译正文；混合页面可以触发，短页面、代码或表单内容和正文已是目标语言的页面不显示。入口会避开网页固定浮窗和 Pi 页面侧栏，Edge 浏览器侧栏已有相同操作时自动去重；窄屏将范围与隐藏操作收进更多菜单。开始前或运行中均可打开“范围”预览，点击标题或正文段落排除、再次点击恢复；预览和取消不调用接口，应用后保留其余已完成译文，只清除被排除的段落或补译新恢复的段落。
- 普通网页快捷面板将“翻译网页正文”作为长文章主入口，Edge 浏览器侧栏也提供轻量控制。扩展只识别主要正文，跳过导航、表单、表格、代码块和独立公式；先翻译当前视口与下一屏，滚动后继续，并可随时暂停、停止后继续或清除。待发送队列会随当前阅读位置重排，眼前段落先于已经滚过的旧队列，正在进行的请求不被取消，主动重试仍保持优先。某段请求超过 350ms 时只在该段下方显示一行浅色等待提示，完成或失败后原位替换；快速请求和排队内容不闪烁或铺满占位，只看原文与主动翻译抢占会及时隐藏。网页控制条与 Edge 侧栏都可直接选择“双语 / 译文 / 原文”，切换不调用翻译接口，动态加载的新段落继承当前阅读模式。“只看译文”仅隐藏已有成功译文的原文；代码、独立公式、未译或失败段落，以及单独隐藏译文的段落仍保留原文，避免空白和信息丢失。无限滚动和前端动态加载的新段落在接近视口后自动加入；相同文本被重新渲染时复用译文，暂停或停止期间不发起新增请求。SPA 换成另一篇正文时会清除旧译文并提示重新开始。每段请求会把文章标题、紧邻上一段和上一段已完成译文作为最多 800 字符的临时参考，帮助理解代词、短段落与上下句关系；参考内容不产生额外请求、不写入历史，模型仍只输出当前段。每段译文在悬停或键盘聚焦时提供复制、隐藏/显示与单段重译，平时不占用额外阅读空间；浏览器会话内首次使用会自动展示约三秒，无悬停设备默认只保留一个“更多”入口。单段重译失败会保留原译文和整页完成状态。某一段因长度、返回格式或 LaTeX 保护失败时，会在该段提供轻量重试入口并继续其他段落；全局控制同步显示待重试数量，连续失败或接口、网络问题则安全暂停。正文运行中发起划词、右键或框选翻译时，当前选区优先，正文显示稍后继续；被替换的当前段静默回队，选区翻译结束后自动续跑。原文 DOM 不被改写，临时段落请求不进入划词历史，也不覆盖侧栏中的最近译文。
- 网页正文完成后，右下角控制条自动收为只显示进度、阅读模式和展开按钮的轻量胶囊；语言仍可在展开后调整，暂停、停止、范围与清除集中到“更多”菜单。手动展开或收起的状态随当前标签页会话恢复，范围预览期间始终完整展开。
- 正文中的 KaTeX、MathJax 与 MathML 内联公式会从 DOM 提取为唯一一份受保护的 TeX；旧版 MathJax 同时存在可见渲染和隐藏源码时不会重复发送，MediaWiki / Wikipedia 的隐藏 MathML 与可见公式图片也会作为一个公式处理。译文中的公式复用本地渲染器生成 MathML，复制、上下文和会话仍保存可编辑的 TeX 源码；独立公式继续保留原文，单个公式渲染失败只回退源码，不把整页改成截图翻译。
- 图片、SVG、Canvas 或没有 TeX 源码的网页公式会从文字请求中安全剔除并保留原网页内容；“只看译文”也不隐藏含这类公式的原段落。译文下方提供轻量“框选识别”，点击即预选当前段落，但仍须用户确认才截图并调用视觉接口，取消不产生请求。
- 同一标签页刷新后，再次打开 Pi Translator 会恢复当前浏览器会话中与网页正文、目标语言及翻译配置完全匹配的译文，并继续处理变化或新增段落；未变化段落不会重复调用接口。正文范围、双语/译文/原文模式、单段隐藏、暂停和停止状态一并恢复，网页控制条与 Edge 侧栏明确显示恢复段数。会话不保存原始 URL 或段落原文；用户主动清除、改变翻译配置、关闭标签页或关闭 Edge 后删除。
- 快捷面板、Edge 浏览器侧栏和网页右下角控制条会同步显示正文当前的目标语言。没有译文时可直接切换；已有译文时先显示已完成段数，并说明继续操作会清除现有译文、重新调用接口。只有用户再次确认后才切换，取消会保留当前语言和译文且不发送请求。
- 工具栏快捷面板新增“框选网页区域”；网页内固定翻译侧栏和 Edge 浏览器侧栏顶部也都提供始终可见的“框选网页”主操作，无论尚未翻译、翻译中还是正在查看已有译文都可直接进入。选框可以拖动、从四角缩放，并可按 `Escape` 取消；取消后恢复原侧栏，不提供整页、自动滚动或连续截图。
- 翻译结果和失败提示提供“调整区域 / 重新框选”：前者恢复原矩形，后者清空选框；打开或调整选框不会请求 API，必须再次确认才发送。
- 键盘用户可按 `Enter` 创建居中选框，用方向键移动、`Shift + 方向键` 调整宽高，并用 `Ctrl + 方向键` 细调。
- 网页框选只有在用户确认后才截取当前可见页中的选定区域，并发送给用户配置的多模态翻译 API；不会改走文字接口，也不发送选框外画面。
- 涉及密码、验证码或支付字段的区域始终禁止发送；截图不写入历史、缓存、设置或诊断记录。
- 快捷面板统一使用“图像翻译”能力名称；浏览器侧栏的历史导航增加“最近译文”可见标签，窄侧栏中的作用更明确。
- 连续翻译可按当前标签页临时暂停，不中断已开始的请求，框选、右键和快捷键仍可主动翻译。Edge 浏览器侧栏也可直接把当前内容切换为中文、英文、日语、德语或法语，后续划选在该标签页内沿用，不改动全局默认语言。
- 浮动翻译卡在 Edge 偶发提前丢失 pointer capture 时仍可完成当前拖动，不再只移动第一小步。
- 开发与 CI 基准升级到 Node.js 24，并更新 GitHub Actions 运行时；重复推送会取消旧验证任务，失败的 Edge 端到端测试会短期保留 Playwright trace，发布文档和验收清单不再写死历史版本号。

## 安装

1. 在本页底部下载 `tex-selection-translator-0.15.0-edge.zip` 并解压。
2. 在 Edge 打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压后的文件夹。
5. 在设置页配置自己的 OpenAI 兼容文字翻译 API；需要翻译网页图像、扫描 PDF 或公式图像时，再配置支持图片输入的视觉 API。

> Edge 扩展商店版本按审核节奏更新；在商店更新前，可从本页 GitHub Release 下载本版本 ZIP。

## 隐私与安全

- 本版本未新增扩展权限，安装包不包含 API Key、审核凭证、网页内容、PDF 正文或截图。
- 网页区域框选只处理当前可见标签页；局部截图必须经过用户明确的发送确认。
- 扩展不自动滚动、不截取完整网页、不连续截图，也不发送选框外内容；敏感表单区域始终被阻止。
- 所有请求直接发送到用户自行配置的 API；PDF.js、KaTeX 与全部可执行代码均随扩展打包，不加载远程代码。
