# Pi Translator v0.12.1

本版本让普通网页、Overleaf 与 PDF 中的连续翻译更顺手：译文可以进入 Edge 原生侧栏，网页本身不再被浮层遮住；短词查询、快捷键检查和复杂 PDF 选区也得到针对性改进。

## 主要更新

- 普通网页与 Overleaf 新增“浏览器侧栏”模式。当前结果可以直接迁入 Edge 原生侧栏，之后继续划词时在独立空间更新，不会重复调用翻译 API。
- 浏览器侧栏支持回看当前标签页的最近译文，并提供“全文 / 逐句”对照；每条长译文会分别记住阅读位置，历史切换和顶部、底部导航在长内容中保持可达。
- 单词和短语可返回贴合当前语境的紧凑释义，并在模型可靠输出时补充读音、词性和常用释义；仍可随时切回普通译文。
- 快捷面板会检查文字翻译配置、Edge 实际快捷键与当前页面支持状态。默认快捷键因冲突未成功分配时，会明确提示并提供设置入口。
- Pi PDF 改善双栏、通栏公式和表格型选区的判断：意外跨栏时优先保留起始栏，真正跨栏选择会尊重拖选意图，顺序可疑的表格可转为可调整框选。
- 完整结果的侧栏入口、显示偏好和失败反馈进一步统一；使用状态正常时保持一行低干扰提示。

## 安装

1. 在本页底部下载 `tex-selection-translator-0.12.1-edge.zip` 并解压。
2. 在 Edge 打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压后的文件夹。
5. 在设置页配置自己的 OpenAI 兼容文字翻译 API；需要扫描 PDF 或公式图像识别时，再配置支持图片输入的视觉 API。

> Microsoft Edge 扩展商店当前提供 v0.9.0。希望立即使用 v0.12.1，请从本页 GitHub Release 下载 ZIP；商店版本会按审核节奏另行更新。

## 隐私与安全

- 本版本未新增扩展权限，安装包不包含 API Key、审核凭证、PDF 正文或截图。
- 最近译文导航、阅读位置、快捷键检查和短词显示均在本机完成，不会因此产生额外 API 请求。
- 只有用户主动触发翻译或图像识别时，选中的文字或确认的 PDF 区域才会发送到用户自行配置的 API。
- PDF.js、KaTeX 与所有可执行代码均随扩展打包，不加载远程代码。
