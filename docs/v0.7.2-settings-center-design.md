# Pi Translator v0.7.2：设置中心设计

## 设计目标

设置页从单个近 3,000 像素高的连续表单改为面向任务的设置中心。所有既有配置和存储格式保持不变，重构只调整信息层级、导航与保存反馈。

## 信息架构

桌面端使用固定左侧导航和右侧单分区内容，移动端自动切换为横向可滑动导航。五个分区分别为：

1. 连接 API；
2. 翻译偏好；
3. 结果与连续侧栏；
4. 页面范围；
5. 支持与迁移。

一次只显示当前分区。当前接口名称和 Key 状态显示在导航顶部，帮助用户快速确认连接状态。

## 渐进展开

术语约束、更多结果设置以及配置迁移与故障排查默认折叠。普通网页网站名单只在用户选择指定网站模式时出现。连接测试和兼容性诊断保留在 API 分区，不再与全局保存操作混合。

## 保存与错误反馈

固定保存栏始终显示“所有设置已保存”或“有未保存的更改”。用户修改任何字段后立即更新状态；保存成功后恢复已保存状态。存在未保存更改时离开页面会触发浏览器确认。

校验失败时界面自动切换到对应分区：API 配置错误进入连接分区，术语错误展开术语约束，网站名单错误进入页面范围。

## 响应式与主题

设置中心在 860 像素以下将左侧导航变为横向标签，在 640 像素以下将双列表单与 API Key 操作改为单列。亮色和暗色模式共享相同的信息层级、焦点状态与保存反馈。
