# Pi Translator v0.4：效率与上架准备

> 状态：已实现
>
> 日期：2026-07-23

## 用户效率

- 工具栏增加快速弹出面板，可切换目标语言。
- 可按当前网站临时暂停自动划词，右键和快捷键保持可用。
- 翻译卡片支持鼠标、触控笔和触摸拖动，并约束在视口内。
- 加载卡片、翻译结果和重试复用用户手动移动的位置。
- `Escape` 或关闭按钮会关闭卡片；进行中的请求同时取消。
- 保存设置后，已打开页面立即收到非敏感公开设置更新。

## 学术一致性

- 增加全局学术术语表，每行使用“原词 = 译词”。
- 最多保存 100 条，每个术语最大 120 个字符。
- 术语表保存在本机，仅在主动翻译时作为翻译约束发送给 DeepSeek。
- 重复源术语按首次出现保留。

## 模型与错误

- 设置页可使用当前输入或已保存的 API Key 调用 `/models`。
- 可用模型动态填充下拉框，自定义名称继续作为兼容兜底。
- 用户错误按鉴权、限流、超时、网络、模型、响应格式和扩展上下文分类。

## 质量与上架

- 新增 Playwright + Microsoft Edge 端到端测试。
- 覆盖划词按钮显示/隐藏、卡片打开/拖动/关闭和快速目标语言切换。
- 增加隐私政策、商店文案、权限理由和审核测试说明。
- 增加 300×300 商店 Logo、440×280 与 1400×560 宣传图。
